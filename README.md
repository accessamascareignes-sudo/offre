# Offre iBora

Page qui affiche l'offre d'un client sur une page, ouverte par le QR code du mode Commercial d'iBora 2.0.

Cette page ne contient aucun prix ni aucune donnée client : chaque offre est entièrement dans le lien du QR code
(après le #, compressée). Le # n'est jamais envoyé au serveur ; rien n'est stocké.

by fullstap
